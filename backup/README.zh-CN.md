# slide-photo-pdf

把会场里拍到的幻灯片照片裁成正面的一页页，再合成一个 PDF。

这些照片通常是坐在座位上拍的。屏幕是斜的，讲者或讲台可能挡住一个角，手机相册又常常把最新的照片排在前面。这个工具找出幻灯片，让你改框，然后导出一个文件。它跑在你自己的电脑上。上传的照片只留在内存里，刷新或关闭页面后就丢掉。

## 能做什么

- 接受 JPEG、PNG、HEIC、WEBP、BMP 和 TIFF。一次会话最多 30 张，单次上传不超过 250 MB。
- 每张照片上画出一个红色四边形。拖圆点移动那个角，拖一条边的中点则平移整条边。放大镜跟着指针走，并且不会伸到照片外面。
- 所有页的框一起收紧或放宽。滑块正中是自动识别的范围，两端大约各收紧或放宽 6%。
- 页面比例可选 16:9、4:3、16:10、3:2，或按检测到的边长。近些年的投影多半是 16:9。输出宽度可选 1280、1920 或 2560，只影响 PDF 的清晰程度。
- 在原图旁边显示拉正后的那一页。手机上预览在原图下面。单击预览可以按输出分辨率检查这一页。
- 一键翻转页序，用来对付相册里新照片在前的情况。
- 填写文件名后下载。默认文件名是 `会议PPT.pdf`。iPhone 上的 Safari 拿到的是一个普通文件链接，可以存到“文件”。
- 自动框看起来不可靠时会标出来，导出前可以先核对四个角。

## 幻灯片是怎么找到的

角经常被挡住，所以不能只靠猜出来的四个角点。程序找的是屏幕的四条边，角放在两条边的交点上。

1. 照片先缩小到长边大约 1100 像素。用几档亮度阈值分别取出最大的亮区域。投影出来的幻灯片通常就是这块区域，但幻灯片里面的白卡片也可能同样亮。
2. 每个区域做成一个或多个四边形：一个贴到附近的直边，一个用轮廓上的长边，还有一个用最外端的点。
3. 每个候选框先临时拉成 16:9，再打分。边切进文字时，边界会显得毛糙，分数更低。拉正之后仍然歪，分数也更低。面积更大的框有一点加分。
4. 在得分最高的框四周，从亮的内部向暗的会场逐条扫描。亮度掉下去的位置拟合成一条直线。四个角就是相邻直线的交点。角本身被人挡住时，只要两条边还有一段看得见，交点仍然可以定出来。
5. 如果找不到可用的亮区域，就退回照片内侧的一个矩形，并把这一页标成不可靠。

导出的那一页，是按你选的比例和宽度，对原图做透视变换得到的。松紧滑块会在变换前，绕框的中心把框放大或缩小。落在照片外面的像素填成白色。每一页以 JPEG 放进同一个 PDF。

命令行用的是同一套识别和拉正，没有手动改框。置信度低时，可以看打印出来的角点，或用 `--debug-dir` 把框和拉正结果写出来检查。

## 仓库里有什么

| 文件 | 作用 |
|---|---|
| `index.html` | 页面：上传、改框、预览、下载 |
| `app.py` | 本地服务。会话和生成好的 PDF 都放在内存里 |
| `detect.py` | 找四边形、拉正一页、写出 PDF |
| `run.sh` | 用 `python3` 启动服务 |

没有账号，也没有单独的数据库。关闭页面时会请服务丢掉这次会话。生成好的 PDF 在下载链接上大约保留 10 分钟。

## 安装和运行

需要 Python 3.10 或更高版本。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

`./run.sh` 做的是同一件事。浏览器打开 http://127.0.0.1:8765/ 。

默认只监听 `127.0.0.1`，端口是 `8765`。

```bash
python3 app.py --host 127.0.0.1 --port 8765
HOST=127.0.0.1 PORT=8765 ./run.sh
```

- `127.0.0.1` 只接受本机连接。
- `0.0.0.0` 或 `*` 监听全部网卡。能访问这台机器的人都能打开页面。上传的照片会留在这台机器的内存里，直到页面关闭或服务停止。没有自己的访问控制时，不要把它暴露到公网。
- 写成 `192.168.1.20` 这样的地址时，只监听那一块网卡。

## 命令行

```bash
python3 detect.py photo1.HEIC photo2.JPG -o slides.pdf
```

- `--aspect` 取 `16:9`、`4:3`、`16:10`、`3:2` 或 `free`。默认 `16:9`。
- `--width` 是页面宽度，单位是像素，范围 640 到 4096。默认 1920。
- `--pad 0.02` 绕中心把框放宽 2%，`--pad -0.02` 则收紧。数值限制在 ±0.35。
- `--debug-dir out` 把每张照片的识别框和拉正结果写到 `out`。

## 限制

- 被人或讲台挡住的内容补不出来。只有还露在外面的屏幕边缘能用来定框。
- 深色幻灯片、屏幕和背景差不多亮，或者页内有一大块白卡片时，框可能跟错矩形。
- 一条边大部分被人挡住时，这条边可能斜着切进幻灯片。需要用手拖回去；滑块只会整体缩放。
- 刷新或关闭页面会丢掉照片。下载链接过期后，重新生成 PDF 即可。
- 这是本机工具，不是在线转换服务。
